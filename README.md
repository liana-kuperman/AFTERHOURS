
# AFTERHOURS 🌙
### The Internet After Dark

Remember when social media was actually fun?

AFTERHOURS is a nostalgic social media prototype inspired by MySpace, Tumblr, and the early days of the internet. I wanted to bring back the feeling of having your own little corner of the internet, where creativity and individuality matter more than having a perfect feed.

**Less scrolling to impress. More posting because you feel like it.**

## 🌐 Live Demo

[Explore AFTERHOURS](https://signal-hurry-55328290.figma.site)

## ✨ Features

- **Customizable Profiles:** Personalize your profile's appearance and layout.
- **Creative Posts:** Share photographs, thoughts, music, and moodboards.
- **Mixtapes:** Create and explore music-inspired collections.
- **Digital Scrapbooks:** Collect photos, quotes, music, and saved posts.
- **Explore:** Discover creative communities and shared interests.
- **Interactive Feed:** Publish posts and interact with content.

## 💻 Development Process

I created AFTERHOURS using Figma Make and continued refining the application through iterative prompting, testing, and manual code adjustments.

During testing, I discovered that buttons inside the scrapbook popups were hidden behind the bottom navigation. I investigated the CSS, adjusted the popup positioning, and tested the changes in both the preview and published application.

This project gave me hands-on experience with AI-assisted development, frontend debugging, user interface design, and application testing.
